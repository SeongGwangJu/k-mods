# 한국어 팩

메뉴·설정 번역(ko-ui)과 작업 상태 한국어(status-ko)를 한 번에 설치해 Claude Code 화면을 한국어로 바꿔요

이 플러그인에는 코드가 없어요. 설치하면 아래 mod가 함께 설치돼요.

- [ko-ui](../../docs/mods/ko-ui.md)
- [작업 상태 한국어](../../docs/mods/status-ko.md) `status-ko`

```
/plugin marketplace add SeongGwangJu/k-mods
/plugin install korean-pack@k-mods
```
