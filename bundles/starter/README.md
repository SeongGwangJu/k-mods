# 추천 세트

처음 설치하기 좋은 추천 세트예요. 모드 상점, 한국어 팩, 메모장, 컨텍스트 막대, 위험 명령 브레이크, 작업 끝 알림을 한 번에 설치해요

이 플러그인에는 코드가 없어요. 설치하면 아래 mod가 함께 설치돼요.

- [모드 상점](../../docs/mods/mod-store.md) `mod-store`
- [한국어 UI 번역 사전](../../docs/mods/ko-ui.md) `ko-ui`
- [작업 상태 한국어](../../docs/mods/status-ko.md) `status-ko`
- [메모장](../../docs/mods/memo-pad.md) `memo-pad`
- [컨텍스트 막대](../../docs/mods/ctx-strip.md) `ctx-strip`
- [위험 명령 브레이크](../../docs/mods/blast-radius-ko.md) `blast-radius-ko`
- [작업 끝 알림](../../docs/mods/done-alarm.md) `done-alarm`

```
/plugin marketplace add SeongGwangJu/k-mods
/plugin install starter@k-mods
```
