# 작업 상태 한국어

작업 중 줄을 "읽는 중 · page.tsx"처럼 지금 하는 일로, 턴이 끝난 줄을 "◇ Opus 5.5  1분 22초 · 도구 14 · 캐시 97% · 14:59"처럼 모델·시간·도구·캐시 한 줄로 한국어로 보여줘요.

## 설치

```
/plugin marketplace add SeongGwangJu/k-mods
/plugin install status-ko@k-mods
```

## 쓰는 법

따로 할 일이 없어요. 설치하면 바로 작업 중 줄과 턴 완료 줄이 한국어로 바뀌어요. 명령어도 없어요.

## 설정 (/config 또는 /plugin configure status-ko@k-mods)

- **palette**: 턴 완료 줄의 색. 기본값 `dark`는 어두운 터미널용 파스텔이에요. 밝은 터미널이면 `theme`(Claude Code 테마 색을 따라감), 회색 배경 터미널(예: #bdbec6 + 야간 모드 필터)이면 `gray`로 바꾸세요.

## 어떻게 동작하나요

네 군데를 가로챕니다.

- **턴이 시작할 때**: 이번 턴에 부른 도구 수를 0으로 되돌려요.
- **도구를 부를 때**: 지금 돌고 있는 도구 이름과 대상(파일명 등)을 기억해 뒀다가, 끝나면 지워요. Claude가 실제로 도구를 쓰는 건 그대로 두고 지켜보기만 해요.
- **턴이 끝날 때**: 걸린 시간·도구 수·캐시 적중률·모델 이름을 기억해 둬요. 이 정보가 바로 다음에 그려질 완료 줄의 재료예요.
- **화면을 그릴 때**: Claude Code가 그리는 두 줄(작업 중 Spinner, 완료 TurnDuration)에 끼어들어 문구만 한국어로 바꿔요. Claude Code의 애니메이션·레이아웃은 그대로 두고 단어만 바꾸는 방식이라, 엔진이 바뀌어도 잘 안 깨져요.

## 권한 (이 mod가 내 컴퓨터에서 하는 일)

없어요. 네트워크도, 파일도, 모델 호출도 하지 않아요. 지금 진행 중인 턴·도구 호출의 정보만 메모리에서 읽고 화면 문구만 바꿔요.

## 한계

- 완료 줄의 도구 수·캐시 정보는 "같은 밀리초 길이(durationMs)"로 짝을 맞춰요. 아주 드물게 두 턴이 정확히 같은 길이로 끝나면 엉뚱한 요약이 붙을 수 있어요. 그래도 시간 자체는 항상 맞아요.
- 완료 줄(TurnDuration)은 터미널에서만 보여요. Desktop 앱에는 안 그려져요(Claude Code 자체가 그 줄을 터미널에서만 그리기 때문). 작업 중 줄(Spinner)은 터미널·Desktop 둘 다 보여요.
