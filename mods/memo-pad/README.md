# 메모장

Claude가 일하는 동안 다음에 시킬 일을 적어 뒀다가, 버튼 한 번으로 입력창에 넣어요.

## 설치

```
/plugin marketplace add SeongGwangJu/k-mods
/plugin install memo-pad@k-mods
```

## 쓰는 법

- `/m`으로 메모장을 열고 닫아요. Claude가 한창 작업 중이어도 바로 열려요.
- 입력창에 메모를 적고 Enter. 바로 목록에 추가돼요.
- 메모 옆 `[넣기]`를 누르면 그 메모가 프롬프트 입력창에 채워져요(전송은 직접 Enter를 눌러야 해요).
- `[x]`를 누르면 그 메모만 지워져요.
- 메모가 하나라도 있으면 프롬프트 아래 힌트 줄 끝에 `✎ 메모 N (/m)`이 붙어서 잊지 않게 해줘요.
- 메모는 작업 폴더(디렉터리)별로 따로 쌓이고, 세션을 끝내도 남아요.

## 설정 (/config 또는 /plugin configure memo-pad@k-mods)

- **palette**: "메모 N" 배지의 색. 기본값 `dark`는 어두운 터미널용 노란 파스텔 칩이에요. 밝은 터미널이면 `theme`, 회색 배경 터미널이면 `gray`(원본처럼 색 없음)로 바꾸세요.

## 어떻게 동작하나요

- **세션이 시작할 때**: `/m` 명령을 등록하고, 지금 작업 폴더에 저장된 메모를 불러와요.
- **`/m`을 실행할 때**: 메모 패널을 열거나(이미 열려 있으면) 닫아요.
- **패널을 그릴 때**: 입력창 하나와 메모 목록(메모마다 [넣기]/[x] 버튼)을 그려요. 메모를 추가·삭제할 때마다 이 플러그인 전용 저장소(`$.store`)에 저장해요.
- **힌트 줄을 그릴 때**: 메모가 있고 패널이 닫혀 있으면, Claude Code가 원래 그리는 줄 끝에 메모 개수만 덧붙여요.

## 권한 (이 mod가 내 컴퓨터에서 하는 일)

이 플러그인 전용 저장소(`$.store`)에 메모 텍스트를 저장해요. 그 외 네트워크·일반 파일·모델 호출은 전혀 없어요.

## 한계

- 메모는 "작업 폴더" 단위로 나뉘어요. 같은 폴더 안에서는 브랜치를 바꾸거나 세션을 새로 시작해도 메모가 이어지지만, 폴더가 다르면 메모도 달라요.
- `[넣기]`는 입력창에 글자를 채울 뿐, 자동으로 보내지는 않아요. Enter는 직접 눌러야 해요.
